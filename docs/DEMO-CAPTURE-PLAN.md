# Remaining product demos

The PayRadar browser demo is published. The remaining recordings need the real product flows below; do not substitute a schematic animation or a landing-page tour for verified functionality.

## LaserDeck PTT — two-device recording

- Use two supported Android devices, no personal chats/photos, and explicitly label the test environment.
- Record version, device models, Android versions and required permissions before filming. No Android device was attached during this session.
- Suggested 30–45 seconds: establish pairing; press PTT on the first device and capture audible receipt on the second; send an example message; show the received example on the other device.
- Film both devices together for the receipt step. Do not edit a successful receipt from a different run into the sequence.
- Optional photo transfer uses an original, nonpersonal example image. Do not state a fixed Bluetooth range without measuring that environment.
- A Bluetooth pairing failure, permission problem or missing physical device is an open validation item, not a completed demo.

## EİP — consent and role-based walkthrough

- Use dedicated test candidate and employer accounts, a synthetic CV/work sample and explicit test-data labels. Never record real applicant data or another user's account.
- Suggested 30–45 seconds: candidate evidence submission with the applicable consent step; employer view of the same example; inspect a report and show which source supports the result.
- First verify the backend and both role permissions. An accessible login page does not prove that submission/reporting works.
- Include the human decision step. Do not present an inference as a verified hiring outcome or claim measured accuracy without a supporting evaluation.
- The full flow was not recorded in this session; a landing-page video is not a substitute.

## PayRadar physical notification follow-up

- Install/update the internal-test release with the enrolled Google account; record device/OS and app version.
- Enable permission and background reminders; inspect registration; create an eligible example reminder.
- Send one test, then capture actual receipt with the app backgrounded/closed as appropriate. Distinguish provider acceptance from visible delivery.
- Do not send repeated tests to all registered devices. No physical-phone receipt is claimed in the published browser video.
